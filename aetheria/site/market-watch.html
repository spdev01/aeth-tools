ตลาด+ (Market+)

← กลับหน้าดาวน์โหลด · คู่มือ Command Center

คืออะไร

ส่วนขยายช่วยค้นหาตลาดกลางแบบละเอียด — กรองตามความสามารถของไอเทม (ความสามารถติดตัว + ออปชันพิเศษ เช่น “ลดดาเมจที่ได้รับ +5%”) และซื้อ/รับของได้ทันที

ใช้ได้เฉพาะเว็บ https://www.aetheria-online.in.th · รองรับ Chrome / Edge และ Zen / Firefox

เวอร์ชันแสดงที่มุมซ้ายบนของหน้าต่าง ตลาด+ (เช่น v25.10.5.1430)

ติดตั้ง — Chrome / Edge (แนะนำ: ชุดติดตั้ง)

  1. ดาวน์โหลด ชุดติดตั้งแนะนำ จากหน้าดาวน์โหลด แล้วแตกไฟล์เป็นโฟลเดอร์ (ข้างในมี chrome\, UPDATE-CHROME.cmd, คู่มือ)
  2. เปิด chrome://extensions (Edge: edge://extensions) → เปิดสวิตช์ Developer mode (มุมขวาบน)
  3. กด Load unpacked → เลือกโฟลเดอร์ chrome ที่แตกออกมา
  4. เปิดหรือรีเฟรชหน้าเกม → จะเห็นปุ่มสีทอง “ตลาด+ ค้นหาละเอียด” มุมขวาล่าง

⚠ เก็บโฟลเดอร์ไว้ในที่ถาวร (ห้ามลบ/ย้าย) เพราะ Chrome จะอ่านจากโฟลเดอร์นี้ทุกครั้งที่เปิดเบราว์เซอร์

ตอนเปิด Chrome จะมีการ์ดเตือน “ส่วนขยายโหมดผู้พัฒนา” — กดปิดได้เลย ไม่กระทบการทำงาน

ติดตั้ง — Zen / Firefox

แบบถาวร (แนะนำ — มีอัปเดตอัตโนมัติ)

  1. ดาวน์โหลดไฟล์ .xpi (ถ้ามีในหน้าดาวน์โหลด)
  2. ลากไฟล์เข้าหน้าต่าง Zen (หรือ about:addons → ไอคอนเฟือง ⚙ → “Install Add-on From File…”)
  3. ยืนยันการติดตั้ง — เสร็จ อยู่ถาวร และจะอัปเดตตัวเองเมื่อมีเวอร์ชันใหม่

แบบชั่วคราว (โหมด dev — ไม่ต้องเซ็นไฟล์)

  1. แตกไฟล์ aetheria-market-plus-firefox.zip เป็นโฟลเดอร์
  2. เปิด about:debugging#/runtime/this-firefox → กด Load Temporary Add-on…
  3. เลือกไฟล์ manifest.json ในโฟลเดอร์ที่แตก (เลือก “ไฟล์” ไม่ใช่โฟลเดอร์)
  4. เปิดหรือรีเฟรชหน้าเกม → ปุ่มสีทองจะขึ้น

หมายเหตุ: แบบชั่วคราวจะหายเมื่อปิด Zen (ต้องโหลดซ้ำ) และไม่มีการอัปเดตอัตโนมัติ

ติดตั้ง — Userscript (ง่ายสุด ใช้ได้ทั้ง Chrome และ Zen)

  1. ติดตั้งส่วนขยาย Tampermonkey หรือ Violentmonkey
  2. เปิดลิงก์ aetheria-market-plus.user.js จากหน้าดาวน์โหลด → กดยืนยันติดตั้ง
  3. เข้าเกม → ปุ่มสีทองจะขึ้น

Userscript จะอัปเดตอัตโนมัติทุกครั้งที่มีเวอร์ชันใหม่

วิธีใช้งาน

  1. กดปุ่ม “ตลาด+ ค้นหาละเอียด” (มุมขวาล่าง — ต้องเข้าเกมก่อน)
  2. เลือก หมวด / ประเภท / ราคา / ความหายาก ที่ต้องการ
  3. กด “สแกนตลาด” — ระบบดึงรายการทั้งหมดของหมวดนั้น (ใช้เวลาสักครู่)
  4. เลือกชิป ความสามารถ เช่น “ลดดาเมจที่ได้รับ” — ผลลัพธ์กรองทันที
    ชิปทั้งสองส่วน (attributes / affixes) จับคู่กับ “ความสามารถทั้งหมดของไอเทม” อัตโนมัติ — เลือกจากส่วนไหนก็เจอเหมือนกัน
    เลือกหลายชิปได้ + เลือกโหมด “ต้องมีทั้งหมด” หรือ “อย่างใดอย่างหนึ่ง” — ดูสรุปตัวกรองที่แถบเหนือรายการเสมอ (แสดงจำนวนที่พบจริง)
  5. กด “ซื้อ” → ยืนยัน → ไอเทมเข้ากระเป๋า (ถ้าเปิด “รับของอัตโนมัติหลังซื้อ”)
    ถ้าไม่เปิด ให้กด “รับของทั้งหมด” เพื่อรับของจากกล่องรับของ

ผลสแกนครั้งล่าสุดถูกจำไว้ — เปิดใหม่ไม่ต้องสแกนซ้ำ (กด “สแกนตลาด” เพื่ออัปเดต · ถ้าเปลี่ยนตัวกรองฝั่งเซิร์ฟเวอร์ ระบบจะเตือนให้สแกนใหม่)

การอัปเดตเวอร์ชัน

  • Chrome (ชุดติดตั้ง): ดับเบิลคลิก UPDATE-CHROME.cmd → รอจนขึ้น “อัปเดตสำเร็จ” → ไปที่ chrome://extensions กดปุ่มรีโหลด (↻) → รีเฟรชหน้าเกม
  • Userscript: อัตโนมัติ
  • Zen (.xpi ถาวร): อัตโนมัติ (เช็คทุก ~วัน หรือ about:addons → Check for updates)

แก้ปัญหาเบื้องต้น

  • ปุ่มไม่ขึ้น → ต้องอยู่เว็บ https://www.aetheria-online.in.th เท่านั้น แล้วรีเฟรชหน้า
  • สแกนไม่สำเร็จ / หมดเวลา → ตรวจว่าตัวละครออนไลน์อยู่ แล้วลองใหม่ (ระบบลองซ้ำให้อัตโนมัติ 3 ครั้ง)
  • ผลลัพธ์ไม่ตรงกับที่ตั้งใจ → ดูแถบสรุปตัวกรองเหนือรายการ (เช่น “ต้องมีทั้งหมด — พบ N รายการ”) ถ้าตัวเลขไม่ตรง ให้กดสแกนตลาดใหม่
  • Chrome ขึ้น “ส่วนขยายเสียหาย/โหลดไม่ได้” หลังรีสตาร์ท → โฟลเดอร์ถูกย้าย/ลบ ให้แตกไฟล์ใหม่แล้ว Load unpacked อีกครั้ง

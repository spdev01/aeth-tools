ตลาด+ (Market+) — ส่วนขยายตลาดกลาง

ค้นหาไอเทมตลาดกลางตามความสามารถ (ความสามารถติดตัว + ออปชันพิเศษ) และซื้อ/รับของได้ทันที — รองรับ Chrome / Edge และ Zen / Firefox
เวอร์ชันล่าสุด: …
⬇ ชุดติดตั้งแนะนำ (Chrome + ตัวอัปเดต + คู่มือ) Userscript (Chrome/Zen) Chrome zip (เดี่ยว)
Zen / Firefox แบบติดตั้งถาวร: ดาวน์โหลดไฟล์ .xpi ที่เซ็นแล้ว (ถ้ามีในหน้านี้) แล้วลากเข้าหน้าต่าง Zen — หากยังไม่มี ให้ใช้ Userscript หรือโหลดแบบชั่วคราวตามคู่มือ
📖 คู่มือติดตั้ง + วิธีใช้งาน

Command Center — ศูนย์บัญชาการบอท

จัดการบัญชี ตัวละคร และบอทหลายตัวสำหรับทดสอบเกม (รันบนเครื่องคุณเอง ผ่าน http://127.0.0.1:4310)
เวอร์ชันล่าสุด: …
⬇ ดาวน์โหลด (zip)
📖 คู่มือติดตั้ง + วิธีใช้งาน

การอัปเดต

  • Userscript: อัปเดตอัตโนมัติ (ไม่ต้องทำอะไร)
  • Chrome (ชุดติดตั้งแนะนำ): ดับเบิลคลิก UPDATE-CHROME.cmd → กดรีโหลดที่ chrome://extensions
  • Zen (.xpi ที่ติดตั้งถาวร): อัปเดตอัตโนมัติเมื่อผู้ดูแลออกเวอร์ชันใหม่
  • Command Center: ดับเบิลคลิก UPDATE-CC.cmd ในโฟลเดอร์โปรแกรม

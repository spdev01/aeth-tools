ความเป็นส่วนตัว

ข้อมูลถูกเก็บในเบราว์เซอร์ของคุณเท่านั้น — เป็นตัวเลขสรุปรายชั่วโมงสั้น ๆ (เก็บย้อนหลัง 72 ชั่วโมง) ไม่มีการส่งข้อมูลขึ้นเซิร์ฟเวอร์ ไม่อ่านบัญชี/รหัสผ่าน และไม่บันทึกข้อความดิบใด ๆ

ติดตั้ง — Chrome / Edge

  1. ดาวน์โหลด aetheria-earnings-chrome.zip แล้วแตกไฟล์เป็นโฟลเดอร์ (เก็บไว้ที่ถาวร อย่าลบ)
  2. เปิด chrome://extensions (Edge: edge://extensions) → เปิดสวิตช์ Developer mode (มุมขวาบน)
  3. กด Load unpacked → เลือกโฟลเดอร์ที่แตกออกมา (โฟลเดอร์ที่มีไฟล์ manifest.json)
  4. เปิดหรือรีเฟรชหน้าเกม → แผง 💰 Earnings จะขึ้นมุมขวาบน

⚠ การ์ดเตือน “ส่วนขยายโหมดผู้พัฒนา” ที่ขึ้นตอนเปิด Chrome — ปิดได้เลย ไม่กระทบการทำงาน

ติดตั้ง — Zen / Firefox

แบบถาวร (.xpi — ถ้ามีในหน้าดาวน์โหลด)

  1. ดาวน์โหลดไฟล์ .xpi ที่เซ็นแล้ว แล้วลากเข้าหน้าต่าง Zen
  2. ยืนยันการติดตั้ง — เสร็จ อยู่ถาวร

แบบชั่วคราว (โหมด dev — ใช้ได้เลย ไม่ต้องเซ็นไฟล์)

  1. แตกไฟล์ aetheria-earnings-firefox.zip เป็นโฟลเดอร์
  2. เปิด about:debugging#/runtime/this-firefox → กด Load Temporary Add-on…
  3. เลือกไฟล์ manifest.json ในโฟลเดอร์ที่แตก (เลือก “ไฟล์” ไม่ใช่โฟลเดอร์)
  4. เปิดหรือรีเฟรชหน้าเกม → แผงจะขึ้น

หมายเหตุ: แบบชั่วคราวจะหายเมื่อปิด Zen (รอบหน้าโหลดซ้ำตามขั้นตอน)

วิธีใช้งาน

  1. เข้าเกม → แผงจะเริ่มที่โหมด 🌟 this session อัตโนมัติ (ตัวละครที่เล่นอยู่)
  2. แถว live ใต้หัวแผงโชว์ ชื่อตัวละคร · จำนวนคิลสะสม · มูลค่าลูทสะสมของเซสชันนี้ — อัปเดตตลอดให้เห็นว่าแถมนับอยู่ (จุดเขียวเต้น = live)
  3. เลือกช่วงเวลา 6h / 12h / 24h · hover แท่งกราฟ เพื่อดูจำนวนคิล / ดรอป / ไอเทมหลักของชั่วโมงนั้น
  4. ย้ายแผง: ลากที่หัวแผง (⠿) — ระบบจำตำแหน่งไว้ให้ · ย่อเป็นแคปซูล 💰 ด้วยปุ่ม – (ลากแคปซูลได้เช่นกัน)
  5. ⏸ / ▶ หยุด-กลับมาจับข้อมูล · 🗑 ล้างประวัติของตัวละครนี้ (กดสองครั้งเพื่อยืนยัน)
  6. โหมดกองเรือ: เปิด Command Center ไว้ที่ http://127.0.0.1:4310 → ช่องรายการด้านบนจะโชว์บอททุกตัวให้เลือกดูรายได้

ตัวเลขจะเริ่มนับเมื่อมีคิล/ดรอป/ขายจริง — ระหว่างรอคิวจะขึ้น “waiting for login” พอเข้าตัวเกมแล้วแถว live จะโชว์ชื่อตัวละครและเริ่มนับทันที

การอัปเดตเวอร์ชัน

  • Chrome / Edge: ดาวน์โหลด zip ใหม่ → แตกไฟล์ทับโฟลเดอร์เดิม → กดปุ่มรีโหลด (↻) ที่ chrome://extensions → รีเฟรชเกม
  • Zen แบบชั่วคราว: ดาวน์โหลด zip ใหม่ แตกไฟล์ แล้วโหลดซ้ำตามขั้นตอน
  • Zen แบบ .xpi ถาวร: ลากไฟล์ .xpi ใหม่ทับได้เลย

แก้ปัญหาเบื้องต้น

  • แผงไม่ขึ้น → ต้องอยู่เว็บ https://www.aetheria-online.in.th เท่านั้น แล้วรีเฟรชหน้า · เช็คว่าส่วนขยายถูกเปิดใช้งานอยู่
  • ตัวเลขไม่ขยับ → เช็คว่าไม่ได้กด ⏸ ค้างไว้ · ตัวเลขจะขยับเมื่อมีคิล/ดรอป/ขายจริง
  • ไม่เห็นรายชื่อบอท → โหมดกองเรือต้องเปิด Command Center ก่อน (โหมดเล่นเองไม่ต้องมีอะไรเพิ่ม)
  • แผงบังมินิแมพ → ลากที่หัวแผงย้ายได้เลย ระบบจำตำแหน่งไว้ให้
  • Zen ขึ้น “not verified / corrupt” → นั่นคือการติดตั้งแบบถาวรด้วยไฟล์ที่ยังไม่เซ็น — ให้ใช้วิธีชั่วคราวตามคู่มือนี้

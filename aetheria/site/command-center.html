คืออะไร

ศูนย์บัญชาการสำหรับจัดการบัญชี / ตัวละคร / บอทหลายตัว สำหรับทดสอบเกม Aetheria — ทำงานบนเครื่องของคุณเอง 100% (เว็บเซิร์ฟเวอร์ใน localhost)

เวอร์ชันแสดงมุมซ้ายบนของหน้า Dashboard (เช่น v25.10.5.1430)

สิ่งที่ต้องมี

  • Node.js 18 ขึ้นไป → nodejs.org (ติดตั้งแบบ LTS)
  • Windows / macOS / Linux

ติดตั้ง

  1. ดาวน์โหลด aetheria-command-center.zip จากหน้าดาวน์โหลด
  2. แตกไฟล์เป็นโฟลเดอร์ เช่น D:\AetheriaCommandCenter (ข้างในมี server\, public\, package.json, UPDATE-CC.cmd)
  3. เปิด Terminal / PowerShell ในโฟลเดอร์นั้น แล้วรัน: 
    npm install
  4. รันเซิร์ฟเวอร์: 
    npm start
  5. เปิดเบราว์เซอร์ไปที่ http://127.0.0.1:4310

วิธีใช้งาน

แท็บ Dashboard — ควบคุมบอท

  • การ์ดบอทแต่ละตัวโชว์สถานะ / เลเวล / แผนที่ / กิจกรรมล่าสุด (ตีมอน, เดินทาง, พัก ฯลฯ)
  • เลือกบอทด้วย checkbox แล้วใช้ปุ่ม: ▶ Play selected / ⏸ Pause selected / ⏹ Stop selected / ⛔ STOP ALL
  • แถบล่าง = log สดรวม (ติ๊ก follow เพื่อเลื่อนตามอัตโนมัติ)

แท็บ Accounts — จัดการบัญชีและตัวละคร

  • Create accounts: กำหนดจำนวน → สร้างบัญชี + ตัวละครอัตโนมัติ (แนะนำทีละ 5–10)
  • Import accounts: นำเข้าบัญชีที่มีอยู่ (บรรทัดละ userId:password)
  • ตารางบัญชี: ดูรหัสผ่านได้ (ปุ่ม reveal / hide / copy) และสร้างตัวละครเพิ่ม / รีเฟรชข้อมูล

แท็บ Stress — เตรียมบอทสำหรับทดสอบ

  • เลือกตัวละครที่จะเข้า roster (include) แล้วกดเริ่ม — บอทจะเข้าสู่เกมและทำงานตามสคริปต์อัตโนมัติ
  • ติดตามสถานะได้ที่แท็บ Dashboard

เปลี่ยนพอร์ต: PORT=5000 npm start · Windows PowerShell: $env:PORT=5000 แล้วค่อย npm start

การอัปเดตเวอร์ชัน

  1. ในโฟลเดอร์โปรแกรม ดับเบิลคลิก UPDATE-CC.cmd → รอจนขึ้น “อัปเดตสำเร็จ” (ข้อมูลใน data\ ไม่ถูกแตะต้อง)
  2. ปิดเซิร์ฟเวอร์เก่า (Ctrl+C) แล้วรัน npm install และ npm start อีกครั้ง

เวอร์ชันมุมซ้ายบนของหน้าเว็บจะเปลี่ยนเป็นเวอร์ชันใหม่ทันที

แก้ปัญหาเบื้องต้น

  • npm ไม่รู้จัก → ยังไม่ได้ติดตั้ง Node.js หรือยังไม่รีสตาร์ท terminal
  • พอร์ต 4310 ถูกใช้อยู่ → ปิดโปรแกรมเดิม หรือเปลี่ยนพอร์ตตามด้านบน
  • เปิดหน้าเว็บแล้วไม่มีข้อมูล → ต้องเปิดในเครื่องเดียวกับที่รันเซิร์ฟเวอร์
  • บอทไม่เริ่ม → ดู log ใน Dashboard (เช่น ติด rate limit ของเกม ให้รอแล้วลองใหม่)
  • ย้ายเครื่อง → คัดลอกทั้งโฟลเดอร์ (รวม data\) ได้เลย

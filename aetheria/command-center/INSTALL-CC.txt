คู่มือติดตั้งและใช้งาน — Aetheria Command Center
==================================================
ศูนย์บัญชาการสำหรับจัดการบัญชี ตัวละคร และบอทหลายตัวสำหรับทดสอบ/stress เกม Aetheria
ทำงานบนเครื่องของคุณเอง 100% (เปิดเป็นเว็บเซิร์ฟเวอร์ใน localhost)


สิ่งที่ต้องมี (Requirements)
----------------------------
- Node.js เวอร์ชัน 18 ขึ้นไป  → https://nodejs.org (ติดตั้งแบบ LTS)
- ระบบปฏิบัติการ: Windows / macOS / Linux


การติดตั้ง (Install)
---------------------
1. ดาวน์โหลดไฟล์ aetheria-command-center.zip (จากหน้าเว็บของผู้ดูแล)
2. แตกไฟล์ zip ออกมาเป็นโฟลเดอร์ เช่น  D:\AetheriaCommandCenter
   (ข้างในจะมี server\, public\, package.json, UPDATE-CC.cmd ฯลฯ)
3. เปิด Terminal / PowerShell ในโฟลเดอร์นั้น แล้วรัน:
       npm install
   (รอสักครู่ — ดาวน์โหลด dependency ครั้งเดียว)
4. รันเซิร์ฟเวอร์:
       npm start
5. เปิดเบราว์เซอร์ไปที่:
       http://127.0.0.1:4310
   จะเห็นหน้า Dashboard พร้อมเลขเวอร์ชันมุมซ้ายบน (v...)


การอัปเดตเวอร์ชันใหม่ (Update)
-------------------------------
เมื่อผู้ดูแลออกเวอร์ชันใหม่:
1. ดับเบิลคลิก  UPDATE-CC.cmd  ในโฟลเดอร์โปรแกรม
   → ระบบจะดาวน์โหลดและแทนที่ไฟล์ให้อัตโนมัติ
   → ข้อมูลบัญชี/บอททั้งหมดในโฟลเดอร์ data\ ไม่ถูกแตะต้อง
2. ปิดเซิร์ฟเวอร์เก่า (Ctrl+C) แล้วรัน  npm install  และ  npm start  อีกครั้ง
   (เวอร์ชันแสดงมุมซ้ายบนของหน้าเว็บจะเปลี่ยนเป็นเวอร์ชันใหม่ทันที)


วิธีใช้งาน (User Guide)
------------------------
■ แท็บ Dashboard — ควบคุมบอทที่กำลังรัน
   - การ์ดบอทแต่ละตัวจะโชว์สถานะ/เลเวล/แผนที่/กิจกรรมล่าสุด (ตีมอน, เดินทาง, พัก ฯลฯ)
   - เลือกบอทด้วย checkbox → ปุ่ม:
       ▶ Play selected    เริ่มบอทที่เลือก (ทำงานตามลำดับ leveling pipeline)
       ⏸ Pause selected   พักบอทที่เลือก (ไม่ฆ่า process)
       ⏹ Stop selected    หยุดบอทที่เลือก
       ⛔ STOP ALL         หยุดทั้งหมด
   - แถบล่าง = log สดแบบรวม (ติ๊ก follow เพื่อเลื่อนตามอัตโนมัติ)

■ แท็บ Accounts — จัดการบัญชีและตัวละคร
   - Create accounts: กำหนดจำนวน สร้างบัญชี + ตัวละครอัตโนมัติ (แนะนำสูงสุดทีละ 5-10)
       * ระบบจะสุ่มชื่อบัญชี/รหัสผ่าน และแสดงความคืบหน้าในกล่อง log
   - Import accounts: นำเข้าบัญชีที่มีอยู่แล้ว (วางบรรทัดละ  userId:password)
   - ตารางบัญชี: ดูชื่อ/รหัสผ่านแต่ละบัญชีได้ (ปุ่ม reveal/hide/copy)
   - สร้างตัวละครเพิ่ม/รีเฟรชข้อมูลตัวละครได้จากปุ่มในแถว

■ แท็บ Stress — เตรียมบอทสำหรับการทดสอบ
   - เลือกตัวละครที่จะเข้า roster (include) แล้วกดเริ่ม
   - บอทจะเข้าสู่เกมและเริ่มทำงานตามสคริปต์ leveling อัตโนมัติ
   - ติดตามสถานะได้ที่แท็บ Dashboard

■ หมายเหตุ
   - เซิร์ฟเวอร์ผูกกับ 127.0.0.1 เท่านั้น (เครื่องอื่นในวงแลนเข้าไม่ได้)
   - เปลี่ยนพอร์ต: ตั้งค่า environment ให้กับ terminal ก่อนรัน:  PORT=5000 npm start
     (Windows PowerShell:  $env:PORT=5000  แล้วค่อย npm start)
   - ก่อนเปิดใช้งานจำนวนมาก ควรทดสอบกับบัญชี demo 1-2 ตัวก่อน


แก้ปัญหาเบื้องต้น (Troubleshooting)
------------------------------------
- npm ไม่รู้จัก → ยังไม่ได้ติดตั้ง Node.js หรือยังไม่รีสตาร์ท terminal
- พอร์ต 4310 ถูกใช้อยู่ → ปิดโปรแกรมเดิม หรือเปลี่ยนพอร์ตด้วย PORT ตามด้านบน
- หน้าเว็บขึ้น but ไม่มีข้อมูล → ตรวจว่าเปิดในเครื่องเดียวกับที่รันเซิร์ฟเวอร์
- บอทไม่เริ่ม → ดู log ใน Dashboard ว่าแจ้งอะไร (บัญชีติด rate limit ให้รอแล้วลองใหม่)
- อยากย้ายเครื่อง → คัดลอกทั้งโฟลเดอร์ (รวม data\) ไปได้เลย

เวอร์ชันของโปรแกรมแสดงที่มุมซ้ายบนของหน้าเว็บ (ข้างคำว่า Command Center)

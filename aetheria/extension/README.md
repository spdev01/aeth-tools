# Aetheria Earnings Overlay (browser extension)

In-game earnings charts with two data sources:

- **🌟 this session** — works standalone for **any player**: tracks the character you are playing right now
  by reading the game's own network traffic in your browser. No server, no logs, nothing uploaded.
  Green bars = estimated loot value (drops × NPC sell price), blue = realized zeny.
- **Fleet bots** — owner mode: when the local Command Center (`http://127.0.0.1:4310`) is running, the
  dropdown also lists your fleet bots and their server-side tracked earnings.

## Install (Edge / Chrome)

1. Keep the `extension` folder somewhere permanent (or unzip the release archive).
2. Open `edge://extensions` (or `chrome://extensions`) → enable **Developer mode** → **Load unpacked**
   → select this folder.
3. Open the game. The panel appears top-right.

## Use

- **Source dropdown**: `🌟 this session` = your live gameplay · other entries = fleet bots (CC mode).
- **6h / 12h / 24h** switches the chart range; **drag** the header to move (position is remembered);
  **–** collapses to a 💰 pill (toolbar icon toggles too); hover a bar for kills/drops.
- **⏸ pause / ▶ resume** — stops capture completely (zero decode cost while paused). The state persists.
- **🗑 clear** — wipes the stored history of the **current character** (press twice to confirm).
- The pill and the footer show which character is being tracked and when it last updated.

## What is stored (and what is not)

- Only compact per-hour counters: estimated value, kills, drop quantity, zeny earned/spent, top items.
  Roughly tens of KB per day of play; trimmed to a rolling 72 hours; kept in `chrome.storage.local`.
- **No raw logs, no frame captures, no uploads.** The only network calls are the game itself and one
  public `wiki-data` fetch per day for item prices (only triggered once you actually get drops).

## Accounting (mirrors the Command Center tracker)

- Drops valued at max NPC sell price; cards/potions/scrolls/wings excluded from the estimate.
- Zeny earned/spent comes from balance changes (with a 90-second login-replay guard).
- If the first drops of a session land before the price table finishes loading, they are queued and
  folded in a moment later.

## Notes

- The game tab must be open to capture (obviously).
- The login queue can delay the game entry; the panel shows "waiting for login" until you're in.
- Fleet mode requires the Command Center running on the same machine; without it the extension is fully
  standalone.

## Dev

`page-hook.js` is the built artifact of `aetheria/ext-test/page-hook.src.js`:

```
cd aetheria/ext-test
npx esbuild page-hook.src.js --bundle --minify --format=iife --target=chrome110 --outfile=../extension/page-hook.js
```

Icons are generated by `aetheria/ext-test/make-icons.mjs`.

Distribution packages are built by `node build.mjs`:

- `dist/chrome/` + `dist/aetheria-earnings-chrome-v<version>.zip` — Chrome/Edge (Load unpacked)
- `dist/firefox/` + `dist/aetheria-earnings-firefox-v<version>.zip` — Firefox/Zen (temporary add-on / `web-ext sign`)
- `dist/INSTALL-*.txt` — install guides to send alongside the zips

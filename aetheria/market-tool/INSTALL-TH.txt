คู่มือติดตั้ง Aetheria Market+ (ตลาด+) — v0.2.0
=================================================

คืออะไร
  ส่วนขยาย (third-party add-on) ช่วยค้นหาตลาดกลางแบบละเอียด — กรองตามความสามารถ
  ของไอเทม (ความสามารถติดตัว + ออปชันพิเศษ เช่น "ลดดาเมจที่ได้รับ +5%")
  และซื้อ/รับของได้ทันที
  ใช้ได้เฉพาะเว็บ: https://www.aetheria-online.in.th
  รองรับ: Chrome / Edge และ Zen / Firefox


=================================================
[A] ติดตั้งบน Chrome / Edge (โหมด Developer — ไม่ต้องมีบัญชี)
=================================================
ข้อดี: ติดตั้งครั้งเดียวอยู่ถาวร (ต่างจาก Zen) — แต่ต้องเก็บโฟลเดอร์ไว้ ห้ามลบ/ย้าย

1. เตรียมโฟลเดอร์: แตกไฟล์ aetheria-market-plus-chrome.zip
   → จะได้โฟลเดอร์ที่ข้างในมี manifest.json, core.js, icons/
   ⚠ เก็บโฟลเดอร์ไว้ในที่ถาวร (ไม่ใช่โฟลเดอร์ Temp/Downloads)
   เพราะ Chrome จะอ่านโฟลเดอร์นี้ทุกครั้งที่เปิดเบราว์เซอร์

2. เปิด Chrome แล้วไปที่: chrome://extensions
   (Edge ไปที่ edge://extensions)

3. เปิดสวิตช์ "Developer mode" (มุมขวาบน)

4. กดปุ่ม "Load unpacked" → เลือกโฟลเดอร์ chrome ที่แตกออกมา

5. "Aetheria Market+ (ตลาด+)" จะขึ้นในลิสต์ = ติดตั้งสำเร็จ

6. เปิดหรือรีเฟรชหน้าเกม https://www.aetheria-online.in.th/play
   → จะเห็นปุ่มสีทอง "ตลาด+ ค้นหาละเอียด" มุมขวาล่าง

หมายเหตุ:
- ตอนเปิด Chrome จะมีการ์ดเตือน "ส่วนขยายโหมดผู้พัฒนา" — กดปิดได้เลย ไม่กระทบการทำงาน
- อัปเดตเวอร์ชันใหม่: วางไฟล์ใหม่ทับในโฟลเดอร์เดิม → ไปที่ chrome://extensions
  → กดไอคอน ↻ (reload) → รีเฟรชหน้าเกม


=================================================
[A2] ขึ้น Chrome Web Store (ให้ผู้ใช้ติดตั้งคลิกเดียว)
=================================================
1. สมัครบัญชีนักพัฒนา (จ่ายครั้งเดียว US$5):
   https://chrome.google.com/webstore/devconsole
2. กด "New item" → อัปโหลดไฟล์ dist/aetheria-market-plus-chrome.zip
3. กรอกรายละเอียดร้านค้า + นโยบายความเป็นส่วนตัว:
   - "ไม่เก็บข้อมูลผู้ใช้"
   - ขอเข้าถึงเฉพาะเว็บ aetheria-online.in.th
4. ส่งตรวจสอบ → เผยแพร่ → แชร์ลิงก์ร้านค้า
   ผู้ใช้กด "Add to Chrome" คลิกเดียว / อัปเดตอัตโนมัติ
5. อัปเดตเวอร์ชัน: แก้ core.js (เพิ่มเลข VERSION) → node build.mjs
   → อัปโหลด zip ใหม่ในหน้า developer console → เผยแพร่


=================================================
[B] ติดตั้งบน Zen / Firefox — ชั่วคราว (โหมด dev)
=================================================
ไม่ต้องมีบัญชี — แต่ส่วนขยายจะหายเมื่อปิด Zen

1. แตกไฟล์ aetheria-market-plus-firefox.zip → ได้โฟลเดอร์ firefox
2. เปิด Zen พิมพ์ในแถบที่อยู่: about:debugging#/runtime/this-firefox
3. กด "Load Temporary Add-on…"
4. เลือกไฟล์ manifest.json ในโฟลเดอร์ firefox (เลือก "ไฟล์" ไม่ใช่โฟลเดอร์)
5. "Aetheria Market+ (ตลาด+)" จะขึ้นในลิสต์ = ใช้งานได้
6. เปิดหรือรีเฟรชหน้าเกม → ปุ่มสีทองจะขึ้น
* หลังปิด Zen ต้องโหลดซ้ำตามขั้นตอน 2–4 (ใช้เวลา ~20 วินาที)


=================================================
[B2] ติดตั้งถาวรบน Zen (ไฟล์ .xpi ที่เซ็นแล้ว)
=================================================
Zen จะไม่ยอมติดตั้งไฟล์ที่ไม่ได้เซ็นแบบถาวร → ต้องเซ็นผ่าน Mozilla (ฟรี ~2 นาที)

สำหรับผู้พัฒนา (ทำครั้งเดียวต่อเวอร์ชัน):
1. เข้าสู่ระบบ https://addons.mozilla.org แล้วสร้าง API keys
   ที่: https://addons.mozilla.org/developers/addon/api/key/
2. รันคำสั่ง:
   npx web-ext sign --source-dir dist/firefox --api-key <KEY> --api-secret <SECRET> --channel unlisted
3. ได้ไฟล์ .xpi ที่เซ็นแล้วในโฟลเดอร์ web-ext-artifacts/

สำหรับผู้ใช้:
1. รับไฟล์ .xpi
2. ลากไฟล์ .xpi เข้าหน้าต่าง Zen
   (หรือ: about:addons → ไอคอนเฟือง ⚙ → "Install Add-on From File…")
3. ยืนยันการติดตั้ง → เสร็จ อยู่ถาวร ข้ามการรีสตาร์ท


=================================================
[C] Userscript (ง่ายสุด — ใช้ได้ทั้ง Chrome และ Zen)
=================================================
1. ติดตั้งส่วนขยาย Tampermonkey หรือ Violentmonkey
2. เปิดไฟล์ aetheria-market-plus.user.js (หรือลากไฟล์เข้าเบราว์เซอร์)
3. กดยืนยันติดตั้งในหน้า Tampermonkey
4. เข้าเกม → ปุ่มสีทองจะขึ้น


=================================================
วิธีใช้งาน
=================================================
1. กดปุ่ม "ตลาด+ ค้นหาละเอียด" (มุมขวาล่างของจอเกม — ต้องเข้าเกมก่อน)
2. เลือก หมวด / ประเภท / ราคา ที่ต้องการ
3. กด "สแกนตลาด" — ระบบดึงรายการทั้งหมดของหมวดนั้น (ใช้เวลาสักครู่)
4. เลือกชิปความสามารถ เช่น "ลดดาเมจที่ได้รับ" → ผลลัพธ์กรองทันที
   (เลือกหลายชิปได้ และเลือกโหมด "ต้องมีทั้งหมด" หรือ "มีอย่างใดอย่างหนึ่ง")
5. กด "ซื้อ" → ยืนยัน → ไอเทมเข้ากระเป๋า (ถ้าเปิด "รับของอัตโนมัติหลังซื้อ")
6. ผลสแกนครั้งล่าสุดถูกจำไว้ — เปิดใหม่ไม่ต้องสแกนซ้ำ (กด "สแกนตลาด" เพื่ออัปเดต)


=================================================
แก้ปัญหาเบื้องต้น
=================================================
- ปุ่มไม่ขึ้น → ต้องอยู่เว็บ https://www.aetheria-online.in.th เท่านั้น แล้วรีเฟรชหน้า
- Chrome ขึ้น "ส่วนขยายเสียหาย/โหลดไม่ได้" หลังรีสตาร์ท → โฟลเดอร์ถูกย้าย/ลบ
  ให้แตกไฟล์ใหม่แล้ว Load unpacked อีกครั้ง
- Zen ขึ้น "ติดตั้งไม่ได้ / not verified" → เป็นไฟล์ที่ยังไม่เซ็น
  ให้ใช้วิธีชั่วคราว (ข้อ B) หรือขอไฟล์ .xpi ที่เซ็นแล้ว (ข้อ B2)
- Zen: ส่วนขยายชั่วคราวหายหลังปิดเบราว์เซอร์ → โหลดซ้ำตามขั้นตอน 2–4

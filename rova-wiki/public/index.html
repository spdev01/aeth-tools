About this tool

This is a standalone wiki for ROVA ONLINE built around one question: what is a monster actually worth per kill?

For every monster it computes EV = Σ drop% × NPC sell price over its drop table, and lets you include or exclude whole item categories (weapons, armor, cards, consumables, materials, ammo, pets) and drop classes (regular / MVP bonus / special) so the number matches the way you play.

Where the data comes from

  • Monster drops + rates, spawns, shops, quests: the game’s own wiki feed (/api/wiki/full).
  • Item names, types and NPC sell prices: the shipped client content database (client.json, native_items).
  • Names for monsters and maps: the official locale files. Icons: the game’s public UI assets.

How to read EV

  • Drop rates are stored per 10,000 (72.00% = 7200). EV per kill = rate ÷ 10,000 × sell price: a 72% drop that sells for 3z adds 2.16z per kill, a 0.02% card that sells for 10z adds 0.002z.
  • The EV column header and the value-scale selector tell you the basis (per kill / per 100 / per 1,000 kills). The same number at different scales is just ×100 or ×1,000 - the per-kill value is shown underneath.
  • Each drop rolls independently, so EV simply adds up. Sell price is what a shop pays you, not market price.
  • Cards are included via the Card toggle - turn them off to see “steady income” EV without jackpot items.
  • Special drops are rare extras tied to certain maps; the monster page lists the maps it can occur on.
  • Buying/selling to the Central Market or players can beat these numbers, but NPC sell value is the guaranteed floor.

Refreshing the data

cd rova-wiki
npm run fetch    # download raw data (through Tor)
npm run build    # rebuild public/data/rova-db.json
npm start        # serve on http://127.0.0.1:4321
